# Codex 综合建模任务：基于参考图制作超高精度写实广府醒狮 3D 模型

## 一、项目总体目标

请基于我提供的《醒狮三视图.png》，使用 Blender 和 Blender Python（bpy）构建一套**高精度、写实、结构完整、材质精致、毛发真实、支持拆解与后续动画交互的广府醒狮三维模型**。

参考图包含正视图、左视图、后视图、俯视图，以及眼部、头顶装饰和尾部局部细节。

最终模型应尽可能接近参考图中的醒狮，而不是制作一只泛化的传统舞狮。

### 核心目标

1. **高度还原外形：** 尽可能还原参考图中狮头、五官、躯干、四肢、尾部及装饰结构的比例和造型。
2. **高质量几何建模：** 创建真实、连续、具有厚度的三维结构，避免简单基础几何体拼接感。
3. **高精度传统纹样：** 还原金红色传统织锦、复杂彩绘、装饰花纹以及织物细节。
4. **电影级写实材质：** 建立高质量 PBR 材质，包括织锦、金属、漆面、眼球、绒毛和丝线。
5. **真实毛发系统：** 创建红色浓密绒边、红色眉毛、白色胡须、脚毛和尾部白色长毛。
6. **完整可编辑结构：** 保持模型层级清晰，各个主要部件独立，便于拆解、修改、材质调整和动画制作。
7. **多视角一致性：** 确保正面、侧面、背面、俯视以及斜前方都具有高质量三维表现。
8. **支持后续网页展示：** 在保留高精度源模型的同时，为未来 Three.js / React Three Fiber 交互展示准备可优化的资产。

### 最终美术风格

- 高精度写实 3D
- 精致传统工艺品质感
- 高质量商业级三维资产表现
- 丰富但有秩序的细节
- 真实毛发和纺织物表面
- 写实物理材质与光照

**禁止将模型简化成低多边形玩具、卡通狮子、普通真实动物或仅由球体、圆柱体和曲线粗略拼接的模型。**

- 根据检查结果进行多轮修正。
- 输出最终模型、渲染结果和项目报告。

不要只输出 Python 代码却不尝试执行，也不要用一张 AI 生成图片假装已经完成 3D 模型。

如果运行环境不支持 Blender，应明确告知具体限制，保留可执行脚本及依赖说明，不得虚构运行、渲染或验收结果。

### 2. 检查已有工程

# 三、第一阶段：整体结构与白模建造

## 目标

建立比例准确、结构完整、形态接近参考图的高质量三维白模。

此阶段不制作最终颜色、纹样和毛发。

### 1. 参考图分析

分析：

- 正视图中的头部比例与左右对称关系
- 左视图中的头身关系、站姿和尾巴方向
- 后视图中的臀部、四肢和尾部结构
- 俯视图中的身体宽度与波浪绒边分布
- 局部特写中的立体装饰层次

参考图是多视图组合展示，不应默认所有视图都具有严格工程正交关系。

禁止简单依据图像像素位置进行机械拼接。

应通过各视图共同推导出合理的三维形态，并在出现矛盾时优先保证结构与视觉逻辑一致。

### 2. 建立整体形体

包括：

- 狮头主体
- 双眼与眉部
- 双耳
- 鼻口
- 上下颌
- 头顶装饰
- 躯干
- 四肢
- 四只狮爪
- 尾部
- 主要绒边体积
- 主要金属装饰体积

### 3. 比例要求

- 狮头巨大、宽阔、饱满，具有醒狮特有的夸张比例。
- 身体相对修长，具有传统舞狮布身造型。
- 前后四肢厚实，具有自然支撑关系。
- 狮头与身体连接流畅。
- 尾巴位于臀部后方，保持参考图中的白色毛束轮廓。
- 各部件从多个观察方向都应成立。

### 4. 白模质量

- 主要曲面连续、自然。
- 避免明显球体与圆柱体的粗糙拼接。
- 不存在严重模型穿插和悬浮问题。
- 不依赖材质或贴图掩盖几何问题。
- 建立必要的布料与装饰厚度。

完成后输出正面、左侧、后面、顶部和斜前方的纯灰模检查图。

如果主要比例明显不符，应先修正，不要继续堆积细节。

# 四、第二阶段：狮头高精度建模

## 目标

将狮头构建成具有高度复杂曲面、精确五官层次和传统装饰特色的高精度几何资产。

**狮头是整只醒狮最重要的视觉核心，必须优先投入建模精力。**

### 1. 头壳

建立：

- 饱满的头部主体
- 向前隆起的额头
- 两侧面颊结构
- 眼部连接曲面
- 鼻口过渡区域
- 下颌连接区域

头壳应呈现连续而有起伏的复杂曲面。

不能使用单个光滑椭球体代替整个头部。

### 2. 眼部系统

重点还原参考图中的大型突出眼睛。

建立独立结构：

- 眼窝
- 多层眼眶
- 外侧装饰眼圈
- 上下眼睑
- 眼球
- 瞳孔
- 眼部金属与彩绘装饰基底

眼球应明显向前突出。

眼框必须具有真实厚度、层叠关系和复杂曲率。

左右眼球保留独立旋转能力。

眼睛应体现传统醒狮威武、灵动、富有表演张力的神态。

### 3. 眉部

创建厚实、夸张、带有弧度变化的眉弓和毛发生长区域。

要求：

- 眉毛呈大幅度弧形结构。
- 部分覆盖眼部上沿。
- 内外侧具有宽度和厚度变化。
- 与额头自然衔接。
- 保留红色短密绒毛的独立生长表面。

不得仅以单根圆管代替眉毛。

### 4. 耳部

参考图中的耳朵向两侧外展，具有宽厚绒边和内侧装饰。

要求：

- 创建有厚度的耳部曲面。
- 明确内外耳层次。
- 耳根与头壳合理连接。
- 外缘预留红色绒毛区域。
- 保留独立摆动的结构和旋转轴。

### 5. 鼻口结构

建立：

- 鼻梁
- 鼻头
- 鼻翼
- 鼻部卷曲装饰
- 两侧鼻口饰件
- 面部口沿装饰

重点表现参考图中复杂的红、白、绿等颜色装饰所对应的实际立体层次。

不要把鼻子建成普通动物式鼻头。

### 6. 嘴巴与下颌

参考图中的醒狮处于张口状态。

建立：

- 上颌
- 下颌
- 上下唇
- 口腔内壁
- 上下牙齿
- 下颌连接结构
- 胡须生长基底

要求：

- 口腔内部具有真实空间深度。
- 上下颌结构能够支持未来开合动画。
- 牙齿呈传统醒狮装饰性排列，而不是肉食动物的尖牙。
- 嘴唇具有厚度和圆润边缘。
- 下颌不应与头壳出现严重的运动干涉。

### 7. 额头中央装饰

建立参考图中的圆形金属装饰：

- 中央球面金属片
- 多层环状边框
- 装饰固定基底
- 外侧浮雕细节

所有部件具有真实厚度和独立材质区域。

### 8. 头顶装饰

还原参考图中逐层向上收束的环状装饰以及顶部球状结构。

要求：

- 各层比例协调。
- 保留不同层级的厚度和倒角。
- 细化连接结构。
- 不得过度拉高或改造成尖锐动物角。

### 9. 脸颊、铃铛和流苏

建立：

- 左右圆形侧饰
- 侧饰装饰环
- 金属连接件
- 小型金属球
- 红色流苏固定帽
- 流苏生长或几何引导结构

保证饰件之间存在合理的固定和悬挂关系。

### 10. 胡须区域

创建胡须根部表面和毛发引导区。

参考图中的白色长胡须应从下颌自然垂落，具有较大的体积感。

本阶段完成生长面和体积分区，最终发丝将在毛发阶段制作。

# 五、第三阶段：狮身、四肢和尾部精细建模

## 目标

建立高质量传统醒狮布身结构，突出织物垂坠、波浪绒边、绣纹承载表面、四肢包布、铃铛装饰与尾部结构。

### 1. 躯干

- 身体具有传统舞狮服饰的布身感。
- 不得制作真实动物肌肉躯干。
- 背部呈自然拱起形态。
- 侧面织锦具有合理的垂坠与褶皱。
- 腹部保留足够空间。
- 身体与四肢、头部和尾部连接自然。
- 建立合理的布料厚度和边缘折叠。

### 2. 波浪形红色绒边

参考图狮身最重要的视觉元素之一是层层分布的红色波浪绒边。

请采用曲线、曲面网格或 Geometry Nodes 创建高精度绒边基底。

要求：

- 多层波浪沿身体分布。
- 绒边具有真实三维截面。
- 上下起伏富有节奏。
- 走向与身体布面自然贴合。
- 绒边宽度、曲率和局部厚度有所变化。
- 不同波浪层之间形成明确遮挡关系。
- 身体前端、后端和腹部绒边自然收束。
- 为后续真实毛发系统预留生长面与方向。

不要直接复制完全相同的正弦波制造机械重复感。

### 3. 四肢

参考图中四肢较为短壮，外部覆盖织锦、红色绒边与金属饰件。

要求：

- 前后腿比例合理。
- 保留自然弯曲和支撑感。
- 腿部呈布料包裹形态。
- 连接处具有适当褶皱。
- 四肢不应呈简单圆柱形。
- 各条腿能够独立选择和后续绑定。

### 4. 狮爪

创建厚实圆润的四只爪子。

- 前端具有多个分隔清晰的趾部。
- 为白色脚毛建立独立生长区域。
- 趾部具有自然体积。
- 脚掌与地面合理接触。
- 局部保留参考图中的深色爪尖特征。
- 不得变成具有巨大尖爪的真实猛兽脚掌。

### 5. 足踝装饰

- 细化织锦装饰带。
- 建立金色铃铛几何体。
- 添加实际连接件。
- 铃铛分布应具有自然节奏。
- 不得让铃铛悬空。
- 预留红色绒毛与白色脚毛之间的层次。

### 6. 尾部

参考图中尾巴以大面积白色长毛为主，带有红色装饰毛束。

建立：

- 尾部连接基座
- 尾巴主体支撑结构
- 白色毛发引导体积
- 红色毛束生长区
- 毛发方向引导曲线

要求：

- 尾巴具有向后延伸的体积。
- 从侧面和俯视角度都应接近参考图。
- 白色长毛具有散开和下垂趋势。
- 根部集中，末端逐渐蓬松。
- 预留独立摆动能力。

# 六、第四阶段：传统纹样、UV 与高精度 PBR 材质

## 目标

将几何模型转换成接近原始参考图视觉质感的高质量醒狮资产。

这是影响最终还原度最重要的阶段之一。

禁止简单将模型赋予纯红色、纯金色，再使用随机噪声假装传统织锦。

### 1. 参考图纹样分析

分析原图中的：

- 金红色传统织锦
- 狮头彩绘
- 螺旋及卷草类装饰
- 金色装饰图案
- 布身上的繁复纹饰
- 不同区域的花纹密度和方向
- 额头、脸颊、耳朵等装饰区域

请优先利用原始参考图作为颜色和纹样依据。

可以在能够准确判断表面关系的区域提取参考纹样进行校正或辅助制作贴图。

但由于参考图是二维多视图拼图，并不能直接得到所有表面的完整 UV 贴图，因此对于不可见或受遮挡区域，需要创建与原图风格一致、空间连续的补充纹样。

不得声称从单张图中精确恢复了所有不可见表面的原始刺绣。

### 2. UV 展开

对主要模型进行合理 UV 展开。

要求：

- 减少明显拉伸与扭曲。
- 重要可见区域具有足够纹理分辨率。
- 左右主要纹样方向协调。
- 波浪绒边与身体布面可以使用独立 UV 或材质区域。
- 合理安排 UV 接缝。
- 重点可见区域优先分配纹理精度。
- 保留可重新烘焙和编辑的 UV 数据。

### 3. 金红织锦材质

创建写实传统织锦材质。

包含：

- 深浅变化的中国红
- 暖金色纹样
- 黑色、绿色等少量传统彩绘点缀
- 细密织物纤维
- 真实织锦反射
- 适度的微观织物凹凸
- 局部刺绣凸起
- 合理的粗糙度变化

织物不能表现成纯塑料或高反光金属板。

### 4. 精细纹样

根据参考图建立有秩序的传统装饰纹样。

要求：

- 纹样随布面曲率自然变化。
- 图案尺寸符合不同区域的装饰尺度。
- 主要纹样有清晰层次和边界。
- 避免随机排列毫无意义的噪声或几何图形。
- 对重要的刺绣区域可结合高度贴图、法线贴图和必要的几何浮雕。
- 对比参考图进行颜色、纹样密度及比例修正。

### 5. 金属材质

用于：

- 额头中央金饰
- 顶部装饰
- 两侧圆形饰件
- 金色铃铛
- 流苏连接金属球

建立具有合理金属度、粗糙度、微小磨痕及真实环境反射的材质。

不同金属区域可以存在适度明暗与粗糙度差异，避免所有部件具有完全相同的金黄色反射。

### 6. 眼睛材质

- 眼球表面具有真实高光。
- 黑色瞳孔富有深度。
- 外部眼圈具有漆面与彩绘层次。
- 不同材料的反射性质明确区分。
- 避免完全镜面化导致眼部缺乏细节。

### 7. 材质贴图输出

尽可能生成或整理：

- Base Color
- Metallic
- Roughness
- Normal
- Ambient Occlusion
- Height（必要时）
- Alpha / Mask（必要时）

高精度离线主模型可以使用 Blender 原生程序化节点与额外的置换系统，但应保留贴图烘焙流程，方便后续生成标准 PBR 的网页交互版本。

# 七、第五阶段：高精度真实毛发系统

## 目标

创建具有真实纤维质感、自然毛流、合理密度及层次的醒狮毛发。

毛发必须尽可能接近参考图，而非普通动物皮毛。

优先考虑当前 Blender 版本兼容的 Hair Curves、Geometry Nodes 等技术。

### 1. 红色短密绒毛

覆盖：

- 眉毛
- 眼眶局部包边
- 面部边缘
- 耳朵外缘
- 身体波浪绒边
- 四肢装饰边缘

要求：

- 毛发短而密集。
- 毛流沿装饰轮廓分布。
- 具有细微长度变化。
- 毛发根部与表面紧密结合。
- 整体呈蓬松、厚实的传统绒边质感。
- 不要出现像草地、钢针或动物鬃毛一样的效果。

### 2. 眉毛毛发

- 比普通装饰短绒更加饱满。

### 3. 白色胡须

- 不要做成整齐排列的白色圆柱或厚重硬片。

### 4. 白色脚毛

- 毛发较胡须短。

### 5. 白色长尾毛

这是毛发系统的另一个重点。

要求：

- 根部相对集中。
- 向后和两侧自然扩散。

- 毛丝存在适度弯曲与重力影响。
- 长短错落，避免机械一致。
- 尾毛具有较高纤维密度。
- 整体保持参考图中的蓬松扇形体积。

### 6. 红色流苏

流苏应呈现：

- 根部集中
- 末端自然下垂
- 有适当的细微分散
- 具有柔软丝线反射特征

# 五、第三阶段：狮身、四肢和尾部精细建模

## 目标

建立高质量传统醒狮布身结构，突出织物垂坠、波浪绒边、绣纹承载表面、四肢包布、铃铛装饰与尾部结构。

- 身体具有传统舞狮服饰的布身感。
- 不得制作真实动物肌肉躯干。
- 背部呈自然拱起形态。
- 侧面织锦具有合理的垂坠与褶皱。
- 腹部保留足够空间。
- 身体与四肢、头部和尾部连接自然。
- 建立合理的布料厚度和边缘折叠。

### 2. 波浪形红色绒边

- 铃铛分布应具有自然节奏。

### 6. 尾部

# 六、第四阶段：传统纹样、UV 与高精度 PBR 材质

## 目标

将几何模型转换成接近原始参考图视觉质感的高质量醒狮资产。

这是影响最终还原度最重要的阶段之一。

禁止简单将模型赋予纯红色、纯金色，再使用随机噪声假装传统织锦。

### 1. 参考图纹样分析

分析原图中的：

- 金红色传统织锦
- 狮头彩绘
- 螺旋及卷草类装饰
- 金色装饰图案
- 布身上的繁复纹饰
- 不同区域的花纹密度和方向
- 额头、脸颊、耳朵等装饰区域

请优先利用原始参考图作为颜色和纹样依据。

可以在能够准确判断表面关系的区域提取参考纹样进行校正或辅助制作贴图。

但由于参考图是二维多视图拼图，并不能直接得到所有表面的完整 UV 贴图，因此对于不可见或受遮挡区域，需要创建与原图风格一致、空间连续的补充纹样。

不得声称从单张图中精确恢复了所有不可见表面的原始刺绣。

### 2. UV 展开

对主要模型进行合理 UV 展开。

要求：

- 减少明显拉伸与扭曲。
- 重要可见区域具有足够纹理分辨率。
- 左右主要纹样方向协调。
- 波浪绒边与身体布面可以使用独立 UV 或材质区域。
- 合理安排 UV 接缝。
- 重点可见区域优先分配纹理精度。
- 保留可重新烘焙和编辑的 UV 数据。

### 3. 金红织锦材质

创建写实传统织锦材质。

包含：

- 深浅变化的中国红
- 暖金色纹样
- 黑色、绿色等少量传统彩绘点缀
- 细密织物纤维
- 真实织锦反射
- 适度的微观织物凹凸
- 局部刺绣凸起
- 合理的粗糙度变化

织物不能表现成纯塑料或高反光金属板。

### 4. 精细纹样

根据参考图建立有秩序的传统装饰纹样。

要求：

- 纹样随布面曲率自然变化。
- 图案尺寸符合不同区域的装饰尺度。
- 主要纹样有清晰层次和边界。
- 避免随机排列毫无意义的噪声或几何图形。
- 对重要的刺绣区域可结合高度贴图、法线贴图和必要的几何浮雕。
- 对比参考图进行颜色、纹样密度及比例修正。

### 5. 金属材质

用于：

- 额头中央金饰
- 顶部装饰
- 两侧圆形饰件
- 金色铃铛
- 流苏连接金属球

建立具有合理金属度、粗糙度、微小磨痕及真实环境反射的材质。

不同金属区域可以存在适度明暗与粗糙度差异，避免所有部件具有完全相同的金黄色反射。

### 6. 眼睛材质

- 眼球表面具有真实高光。
- 黑色瞳孔富有深度。
- 外部眼圈具有漆面与彩绘层次。
- 不同材料的反射性质明确区分。
- 避免完全镜面化导致眼部缺乏细节。

### 7. 材质贴图输出

尽可能生成或整理：

- Base Color
- Metallic
- Roughness
- Normal
- Ambient Occlusion
- Height（必要时）
- Alpha / Mask（必要时）

高精度离线主模型可以使用 Blender 原生程序化节点与额外的置换系统，但应保留贴图烘焙流程，方便后续生成标准 PBR 的网页交互版本。

# 七、第五阶段：高精度真实毛发系统

## 目标

创建具有真实纤维质感、自然毛流、合理密度及层次的醒狮毛发。

毛发必须尽可能接近参考图，而非普通动物皮毛。

优先考虑当前 Blender 版本兼容的 Hair Curves、Geometry Nodes 等技术。

### 1. 红色短密绒毛

覆盖：

- 眉毛
- 眼眶局部包边
- 面部边缘
- 耳朵外缘
- 身体波浪绒边
- 四肢装饰边缘

要求：

- 毛发短而密集。
- 毛流沿装饰轮廓分布。
- 具有细微长度变化。
- 毛发根部与表面紧密结合。
- 整体呈蓬松、厚实的传统绒边质感。
- 不要出现像草地、钢针或动物鬃毛一样的效果。

### 2. 眉毛毛发

- 比普通装饰短绒更加饱满。
- 具有明确的弯曲方向。
- 与眉部几何体紧密贴合。
- 内外侧毛量自然过渡。
- 在不遮盖眼睛关键结构的情况下形成浓密视觉轮廓。

### 3. 白色胡须

参考图中的下巴白色长毛应具有柔软、顺滑、自然垂落的特征。

要求：

- 从下颌根部自然生长。
- 具有不同长度的毛束。
- 形成丰富但有秩序的层次。
- 毛丝顺重力自然下垂。
- 局部存在自然弯曲。
- 不要做成整齐排列的白色圆柱或厚重硬片。

### 4. 白色脚毛

- 覆盖四只狮爪的相应区域。
- 毛发较胡须短。
- 沿脚趾和脚掌轮廓自然延伸。
- 保持脚趾结构可辨认。
- 不要完全遮住脚部体积。

### 5. 白色长尾毛

这是毛发系统的另一个重点。

要求：

- 根部相对集中。
- 向后和两侧自然扩散。
- 具有明显的毛束层级。
- 毛丝存在适度弯曲与重力影响。
- 长短错落，避免机械一致。
- 尾毛具有较高纤维密度。
- 整体保持参考图中的蓬松扇形体积。
- 与红色装饰毛束具有清晰的颜色分区。

### 6. 红色流苏

与普通绒毛区别处理。

流苏应呈现：

- 由细丝线构成的束状结构
- 根部集中
- 末端自然下垂
- 有适当的细微分散
- 具有柔软丝线反射特征

### 7. 毛发质量和性能

建立可调节参数，例如：

- 毛发密度
- 长度
- 粗细
- 弯曲
- 聚束程度
- 随机变化
- 毛流方向
- 根尖粗细变化

对于高精度源文件优先追求视觉质量。

对于后续实时网页资产，应另外准备毛发卡片、可实例化几何体或其他可导出的毛发替代方案。

不要假设 Blender 原生曲线毛发能够原样导出到 GLB 并在 Three.js 中保持完全一致的效果。

# 十三、必须避免的常见失败情况

以下结果不能被视为高精度建模完成：

1. 使用多个基础球体拼凑狮头。
2. 使用圆柱体简单代替狮身和四肢。
3. 仅仅贴一张参考图片假装完整三维结构。
4. 只有正面视角像参考图，侧面和背面明显失真。
5. 完全忽略头部复杂装饰结构。
6. 用简单重复波浪线代替立体绒边。
7. 将金红织锦简化成红色材质与随机金色斑点。
8. 使用粗大的曲线代替真实毛发。
9. 使用统一长度、统一方向的毛丝导致塑料刷子般的质感。
10. 将全部部件合并为单个无法拆解的对象。
11. 只交付渲染图，不交付可编辑的三维资产。
12. 未运行 Blender 却声称完成建模。
13. 不进行多视角对比就判定还原成功。
14. 自动执行脚本发生错误后仍将失败结果标记为成功。
15. 使用 AI 生成的二维效果图冒充 Blender 三维渲染。
