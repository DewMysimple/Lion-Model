# 系统架构

## 模块职责与边界

| 模块 | 职责与边界 |
| --- | --- |
| `references/` | 原参考图、视图裁切、建模简述与生成参考；生成图是辅助资料 |
| `generated/` | Aholo Lux3D 原始模型和资源包，保留来源证据，不直接覆盖主文件 |
| `blender/` | 本地生成主文件已忽略 Git；真实阶段归 `checkpoints/` 且保留 LFS，部件归 `components/`，实验归 `studies/` |
| `textures/` | 原始图集、局部修订图集、织锦合成图及微织物法线 |
| `scripts/` | 分部件、材质、毛丝、局部修订、导出、验证及打包工具 |
| `exports/` | 两份主 GLB 交换文件；阶段/材质实验导出归 `studies/`，部件导出归 `components/` |
| `renders/final/`、`renders/studies/` | 正式效果视图与实验对照图，用于艺术核对 |
| `docs/`、`wiki_memory/` | 正式实测报告与工程记忆；报告是证据，记忆恢复当前上下文 |
| `delivery/` | 本地 ZIP 与校验侧车；可再生成的交付包不重复充当版本源 |

工程没有需要部署的网页或服务，用户明确不需要网页模型预览。本轮已迁移 checkpoint、study、实验渲染和实验导出，修正脚本路径，并清除网页文件及无关产物。正式渲染目录保留 19 张，草稿对照归实验区；清理量为 3,598,156,789 字节，具体路径见清理清单。

## 数据流与依赖

实际构建链为 CMD → `scripts/build_model.ps1` → Blender 内置 Python 的 `build_native_model.py`。包装脚本检查 12 个真实数据输入和 15 个 Python 模块，加 CMD/PS 配方共 29 个哈希；缺失/LFS 指针可触发定向 `git lfs pull`，不会把指针当模型。它不需外部 Python 或再次云端生成。

独立暂存项目只复制数据/源码，不复制旧主文件；依次运行组装、材质边界修正、Trim 毛丝/限位定稿、额头与金饰细节四阶段。先验证暂存主文件，发布并删除暂存，再新进程重开实际输出。14 图片打包为相对路径、清除库 datablock，不依赖已删除暂存。结构及完整原生资产语义对照均实测 pass。

原始整狮 G1（任务 4054240）有 286,200 个三角面；去掉旧头部 43,408 面后保留 242,792 面。独立狮头 G1（4055287）保留 285,606 面。原生合计 528,398 个来源面引用，按 `source_asset` / `source_asset_id` 与 FACE 域 `source_face_index` 保留出处，分为 20 个可编辑来源网格。[原生验证](../../docs/final_master_verification.json) 逐来源检查保留面集合恰好出现一次。

`Lion_Root` 组织部件与 `Pivot_*`。主文件实测 256 个模型对象（155 Mesh、69 Curve、32 Empty）；其中 66 个毛丝 Curve 共 980,957 根 Bezier 毛丝，3,121,088 个控制点。曲线随父变换移动，改变源网格形体后需重新贴根或梳理；这不是完整骨骼与蒙皮系统。

织锦新图 `textures/brocade_new/brocade_reference_synthesis.png` 为 1254² 合成设计；2048² `body_micro_weave_normal_2048.png` 提供微织物法线。身体通过 UV1 柱状映射约 0.20 m 重复，额头只替换 371 个面；图集、原 UV 与部分旧材质继续保留。[模型报告](../../docs/Final_Model_Report.md) 说明合成花纹及边界误差，不能把像素清晰度当作刺绣复刻。

完整原生验证在引用检查点比对来源后列出一个 `Lion_Detailed_Parts.blend` library datablock，当前路径为 `blender/checkpoints/` 且存在。但 [本轮实际初始重开](../../docs/relocation_dependency_check.json) 的 libraries 和 linked_ids 为空，14 个图片均 packed。两份证据核查范围和时点不同，不能把检查期间出现的库条目当作主文件初始运行依赖。

GLB 将毛丝抽样为 131,276 根网格代理，共 3,524,821 个三角形；来源面因 77 个已具体审计的重复顶点三角形折叠为 528,321 面。Draco 使用位置 20 bit、UV 16 bit、法线 12 bit，需解码器；格式通过不证明艺术外观一致。

## 运行与部署

其他 Windows 环境按工程 README 获取 LFS 资源后，在仓库执行 `build_model.cmd "F:\Blender\blender.exe"`，默认生成忽略 Git 的主文件。构建实际要求 Blender 5.0.x；显式第二参数可另选 `.blend` 输出。已有输出默认保留，只有 `-Force` 才替换并留下备份。可用 `LION_BLENDER` 或 PATH 指定实际 Blender；`-NoLfsPull` 适用于资源已齐全的离线场景。CMD/PS5/Blender5.0 实测通过，其他版本未验证。

持续编辑以主文件另存检查点、必要脚本局部修改、重开技术检查与细节渲染对照为主。重建脚本会写 `.blend`，不能在不了解输入阶段时直接运行。GLB 是次级交换产物；本轮无需新增云端生成或服务部署。

`.gitattributes` 使真实阶段、模型、图像、来源 ZIP 和数组使用 LFS。`.gitignore` 已忽略主文件、`delivery/` 和 `cache/` 等，新分支索引不含主文件；旧本轮未发布引用还待替换，不能称全历史已完成排除。200/200 LFS 上传完成不等于分支发布，远端及最终包待验收。
