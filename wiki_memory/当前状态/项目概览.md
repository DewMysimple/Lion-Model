# 项目概览

## 项目目标与阶段

以参考图中的广府醒狮为目标，持续提高形体、毛发、织锦、金饰和近景表面质量，并保持可编辑的 Blender 原生工程。当前已有双来源合成及局部细节改造后的模型，适合继续逐部件编辑；头冠、鼻部、腿部和部分片状毛基底仍需重建，不能称为超高精度实物复刻。[模型报告](../../docs/Final_Model_Report.md) 与 [已知问题](已知问题.md) 分别说明已实现范围和缺陷。

本轮已建立 standard 记忆、整理目录/脚本并移除网页和无关产物。main 发布历史不含主文件；CMD 隔离重建及真实新克隆的默认输出构建、独立重开、便携资产对照均 pass。新克隆的两个大阶段文件使用 SHA 匹配缓存，不能称完全冷网络下载。最终证据提交和离线包刷新由本轮交付流程收尾，模型艺术内容未改。

## 工作区背景

构建代码和资产基线为已发布 main `5e89e6985503086582095aa5453f82436010c129`，目标 `https://github.com/DewMysimple/Lion-Model.git`。发布时实际 HEAD、origin/main、远端 heads 一致，引用历史无主文件路径，本地原件保留且忽略。200 个 LFS 路径有 199 个不同对象。该 revision 是实测代码基线；后续最终证据/记忆提交会使文档 HEAD 变化，不能将它冒称最终最新提交。

此前 LFS 发布拒绝已解决。`docs/remote_build_verification.json` 记录真实 GitHub 新克隆该基线，起初无主文件，默认 CMD 重建及便携对照通过。发布后的证据/记忆属于本轮追加变更，最后同步提交与包状态看本轮维护日志。

接续重新检查分支、HEAD、工作树及远端；本页记录实测基线和范围，不代表未来分支状态。离线包及校验侧车均在 `delivery/`，最终包验收以相邻验证报告与维护日志为准。
