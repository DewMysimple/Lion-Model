# 项目概览

## 项目目标与阶段

以参考图中的广府醒狮为目标，持续提高形体、毛发、织锦、金饰和近景表面质量，并保持可编辑的 Blender 原生工程。当前已有双来源合成及局部细节改造后的模型，适合继续逐部件编辑；头冠、鼻部、腿部和部分片状毛基底仍需重建，不能称为超高精度实物复刻。[模型报告](../../docs/Final_Model_Report.md) 与 [已知问题](已知问题.md) 分别说明已实现范围和缺陷。

本轮是工程维护：standard 正文、目录和脚本路径已整理，网页及无关产物已清除。主 `.blend` 已设为本地忽略产物，CMD 从阶段/素材重建并独立重开通过，不复制旧主文件；完整原生资产语义比对也 pass。尚需排除主文件的 Git 历史发布、远端新克隆及最终包。该维护没有修改艺术内容，也不改变其完成度。

## 工作区背景

工程根是 `Lion_3D_Project/`，有效记忆根是其下 `wiki_memory/`。目标远端仍为 `https://github.com/DewMysimple/Lion-Model.git`。此前已形成仅在本机的资产/文档提交；首轮分支发布被 GitHub 的 LFS 对象完整性检查拒绝，后续 `git lfs push --all` 已完成 200/200 对象上传，但远端分支尚未发布。

当前实际工作分支为尚无提交的 `reproducible-main`，新索引不含主文件且 `.gitignore` 已忽略它；旧 `main` 仍保存本轮早期未发布历史，待新提交完成后统一替换为 main。只整理本轮 Agent 自己未发布的提交，保留本地主文件及其他资产。完整发布历史与远端分支仍需验收，不能把新索引排除当作所有引用已排除。

接续必须重新检查当前分支、HEAD、工作树与远端引用；此处是维护中的恢复点，不是后续分支状态。目录整理和协议内容属于本轮本地变更。
